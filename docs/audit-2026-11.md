# Audit of the v1 chirp pipeline (2026-11-12)

Read-only audit of chirpdetector, gridtools and the data assets behind the
paper's production run (2024-06-16). It extends `docs/known_issues.md` in
`~/wrk/analyses/chirp_competition` (items D1–D9). New items are numbered
N (chirpdetector), G (gridtools) and A (assets).

Reference versions: chirpdetector tag `paper-chirp-competition-v1` (3447105),
gridtools `df7f504`. chirpdetector `main` (41dee8f) and gridtools `main`
(6cbebcf) are later and broken (N9, G1).

Abbreviations: TH = `~/wrk/analyses/mscthesis_chirpdetection`,
CC = `~/wrk/analyses/chirp_competition`.

## Summary

1. No real-data ground truth for the chirp emitter exists anywhere. The
   assignment model has only ever been evaluated on simulations, and the
   reported numbers come from a different model than the deployed one (D1).
2. The simulated spatial field carries almost no information about which fish
   emitted a chirp (G3), so the simulations could not teach spatial assignment.
3. The YOLO train/val/test split is random by image across the same recordings
   and across clean/noisy twins of the same simulation (N2). The production
   model's validation metrics are therefore optimistic. The only clean number is
   the real-data benchmark: P 1.00 (CI 0.986–1), R 0.764 (0.715–0.809),
   F1 0.866 at threshold 0.5, 335 labels.
4. Neither training set can be regenerated: raw simulations are gone, the
   template source recordings are gone, the simulator crashes at HEAD and the
   converter at v1 blocks on `input()` in synthetic mode (A2, A1, G1, N8).
5. The spectrogram front end uses a 205 ms window for 10–30 ms chirps and sums
   dB values across electrodes (N15, N16).

Realism gaps relevant to training: no independent per-electrode noise, no
50 Hz hum, no dead electrodes or clipping; no rises; no ΔF < 20 Hz and no track
crossings; tracks are perfect (no gaps, swaps, or harmonic tracks); chirp
timing independent across fish (near-simultaneous chirps rare); 30–80%
amplitude dip for all chirps (likely too deep for small chirps; to be checked
against data); templates only from the higher-EODf fish and probably carry
beat ripple from the source recording; all simulations 3×3 while 19 of 33
trials use 15 electrodes.

(fails at import), `ChirpDataV2`, `preprocessing.remove_*`, `config/prepro.toml`,
